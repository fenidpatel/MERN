# 💰 Expense Tracker (MERN Stack)

A simple full-stack Expense Tracker application built using **MongoDB, Express, React, and Node.js**.  
It allows users to add, edit, delete, and view expenses with categories like Food, Travel, etc.

---

## 🚀 Features

- ➕ Add new expenses
- ✏️ Edit existing expenses
- ❌ Delete expenses
- 📊 View spending overview
- 🧾 Categorize expenses (Food, Travel, etc.)
- 🔗 REST API with Express & MongoDB
- ⚛️ React frontend with dynamic UI

---

## 🛠️ Tech Stack

**Frontend:**
- React
- Axios
- CSS

**Backend:**
- Node.js
- Express.js
- MongoDB
- Mongoose
